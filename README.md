# TankWise · 小單位儲水式電熱水器決策工具

HacKU 2026 Problem 3 原型：香港小單位住戶在買或換熱水器前，輸入多人洗澡需求、可安裝空間及**機身**預算；網頁先模擬容量、設溫和開機時間，再推薦符合條件的真實品牌與型號、標價及商品連結。

## 啟動

需要 Python 3.9 或以上，無需安裝第三方套件。在此分支的倉庫根目錄執行：

```bash
python3 -m app.server
```

開啟 [http://127.0.0.1:8765](http://127.0.0.1:8765)。檢查模型：

```bash
python3 -m unittest discover -s tests -v
```

## 目前可做什麼

- 輸入 1–4 人各自洗澡時間、每人最多等候回溫時間、花灑流量、入水溫度及電價假設。
- 輸入可安裝位置的**寬 × 高 × 深（cm）**、最大水箱容量及**機身售價預算（HK$）**。
- 比較目前熱水器與建議配置的多人洗澡結果，並展示 80 組抽象配置的取捨。
- 對真實產品庫逐一檢查機身尺寸、機身售價、容量，然後用同一模型模擬每款產品的設溫與開機策略；提供品牌、完整型號、價格、商品與規格連結。
- 若沒有符合空間、預算和洗澡需求的型號，明確說明無匹配結果。

產品資料在 [`data/products.csv`](data/products.csv)，目前收錄真富及德國寶的 4 款 3 kW 中央儲水式產品。價格為 **2026-10-02 查閱商戶網頁時的「其他付款方式優惠價」**，只計機身，不包含安裝、送貨或拆舊機；價格及庫存可能改變。尺寸按指定直掛方向比較機身，並未計喉管、接線或維修空間。實際安裝須由合資格人士確認。

**洗澡時間、等待和待機電費仍屬模擬**。產品的實測出水曲線尚未用於標定；不同產品暫沿用按容量估算的保溫熱損失，不能把結果視為保證供水時間或完整電費。資料來源、計算方法及待完成標定見 [`docs/model.md`](docs/model.md)。

所有開發成果只存放在 `Jim's-codex/water-heater-model` 分支；此分支的產品需求以本 README 和使用者最新要求為準。
