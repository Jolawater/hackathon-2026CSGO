[部署到 Render（JESON 分支）](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2FJolawater%2Fhackathon-2026CSGO%2Ftree%2FJESON)

部署配置已包括前端建置、Python 計算服務及免費方案。點擊後在自己的 Render 帳戶審閱並建立服務；成功後會取得公開網址。此連結是部署入口，不是已上線的網站。免費服務會在閒置後休眠，首次訪問需等待喚醒；不會自動升級付費方案。

香港村屋天台太陽能試算工具。回答七組問題，比較鄰屋遮擋、面板排布、安裝報價和回本時間。結果屬模擬，並非工程設計或回報保證。

本分支 **JESON** 保留最新 RoofSun 專案，程式位於 [roofsun/](roofsun/)。以 Jim's-RoofSun-HK 的 a05e5ad 為基線加入四周鄰屋、介紹首屏、頁面與性能改進；Jim 的分支不受本次整理影響。
