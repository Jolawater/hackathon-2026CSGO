# RoofSun 2.4：更容易填写，也能直接操作天台

此版本沿用 Jim 的 `cadf2e2`，在 `JESON-ROOFTOPJIM` 开发。没有新增真实访谈、安装记录或屋顶实测准确率声明。

## 用户流程

1. 首次使用按所在地、预算与用电、天台尺寸、邻楼情况、报价与回本目标、核对记录分六步输入；也可明确选择香港演示。
2. 数字可直接打字、删空、输入小数。编辑过程中暂时空白不变成 0；离开空白字段会恢复最后有效值。超范围数字在结束编辑时按控件范围处理。
3. 改动立刻进入 3D 草稿预览。右下角只在有改动时出现“确认并保留”“取消修改”。财务结果及浏览器持久保存以确认值为准。计算期间保留上一幅场景并注明正在更新。
4. 专业字段统一收进“更专业的参数调整”。它们仍参与模型，收起不表示已经测量或不重要。
5. 方案文件放在折叠的“方案管理”中，称为打开已保存方案、下载方案备份。导入先作为草稿；香港旧版文件仍可导入。外地方案采用独立区域格式，避免把香港收益或货币误套到外地。

## 可操作的 3D

- 拖动环看，滚轮／双指缩放，限制最远视距。指南针跟随相机，北向同时考虑天台旋转。
- 屋顶使用本地程序生成的混凝土纹理、接缝及低围墙细节，取消坐标网格。围墙与展示楼高仅为画面细节，不增加未测量的能量遮挡。
- 尺寸默认在鼠标指向屋顶／面板时出现，手机可点按；可关闭尺寸提示。
- “放置面板”支持整组或单块拖动；“旋转面板”允许围绕屋顶中心拖动改变共同朝向。单块位置会送往后端，检查边界、碰撞及所选排间检修距离。所有面板仍共用倾角及朝向，没有任意单板朝向或电气组串模型。
- 可输入邻楼矩形尺寸、位置与高出天台的高度，同时用于场景和中心射线遮挡近似。旧天际角仍可用，但同一建筑不要重复录入。
- 月份、全天时间线、播放、暂停、速度同步驱动真实地点的太阳位置、黄色光线、阴影与日夜亮度。移除近处太阳球，改成远处白色天光。显示插值不参与年度发电求解。

重要局限：实时渲染阴影不是年度求解器。能量仍使用已记录的排间相邻遮挡、有限排宽及面板中心射线近似。任意手动位置不意味着获得高精度光线追踪、结构安全或安装许可。

## 深圳与伦敦

- 每城保存 NASA POWER 2023、2024、2025 年逐时辐照与温度；年度分别有 8760、8784、8760 条记录。使用城市坐标、当地时区及 CNY／GBP。文件旁的元数据保存具体请求 URL、单位、时间标准与获取记录；`GET /api/regions` 返回来源和数据指纹。
- 官方数据服务说明：[NASA POWER](https://power.larc.nasa.gov/docs/services/api/temporal/)。这些是气象网格参考年，不是该屋顶实测或未来天气预报；附近城市可能落在同一网格。
- 购电价与售电价由用户输入，初始为 0；自用电量抵消购买，其余电量售出，不重复计收益。若提供月用电，自用电量不超过该月需求。自用比例仍是假设，尚未做逐时负载匹配。
- 香港 FiT 截止日期不截断外地收益。外地使用固定合同价格情景，不预测税项、补贴或未来合同变化。深圳的[官方政策背景](https://fgw.sz.gov.cn/gkmlpt/content/10/10353/mpost_10353813.html)不作为当前统一电价；英国 [Ofgem SEG 说明](https://www.ofgem.gov.uk/environmental-and-social-schemes/smart-export-guarantee-seg)也不意味着每家供应商同价。
- 外地的覆盖比例和承重上限为可编辑筛选假设，不是套用香港村屋法规。初始维护、固定费用及更换费为 0，须按实际报价补充，否则回本可能偏乐观。
- 外地页提供基础建议、3D、地区保存及备份；香港原有详细证据、参考案例和收支分析页面仍保留。香港气象站对照不能被当作深圳或伦敦的实测验证。

## 比赛关联

先确定预算与年度用电目标，再比较投资、发电、遮挡与回本；直接移动面板帮助理解这些冲突。3D 的作用是解释输入与结果，不独立作为数学模型可靠性的证据。没有符合全部约束的方案时应显示未找到，不强行推荐。

## 检查入口

- `python -m pytest -q`：原有模型回归及外地天气／计价、手动位置、邻楼遮挡新增案例。
- `python scripts/validate.py`：重建带源码／数据指纹的原有物理对照报告。
- `npm run build`
- `npm run test:browser`：保存、取消、输入、真实太阳方向变化、指南针、推荐去重、双语与手机布局。
- `node scripts/scene-browser-test.mjs`：尺寸悬停、单块拖动、直接旋转及草稿不覆盖保存。
- `node scripts/regional-browser-test.mjs`：两城填写、电价、保存恢复、备份和手机版。
- `node scripts/owner-browser-test.mjs`：证据报告状态与错误处理。

浏览器脚本可用 `ROOFSUN_TEST_URL` 指向本机服务，并用 `ROOFSUN_BROWSER_CHANNEL=msedge` 选择 Edge。这些属于软件及物理一致性检查，不是独立硬件实验。
