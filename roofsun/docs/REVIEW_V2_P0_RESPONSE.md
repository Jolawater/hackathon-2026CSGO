## 沒有照抄的部分及原因 / Deliberate differences

- **35° 示例並未硬改成合規。** 65 m² 示例若要求 18 塊、0.3 m 間隙及 50% 覆蓋，35° 超出限制；40° 可符合這些初步條件。降低間隙假設才可容納 35°。40° 不代表風荷載或結構設計已通過。
- **不保證財務推薦必定不同。** 預設 HK$25,000/kW 下，最高 NPV 與最快持續回本可能選到同一方案；較低的假設報價測試可產生差異。不能為符合故事而編造數值或故意推薦次佳方案。總發電與單位容量發電的物理取捨仍存在。
- **沒有宣稱示例物業已合法。** 只核對有蓋面積尺寸上限；沒有物業地址、批准文件、實測、錨固設計或結構報告。
- **沒有執行 Windows 上不存在於本機的腳本。** 使用本專案新增的模型與瀏覽器回歸測試重現條件；未聲稱執行使用者提供的 `D:\HackU\...` 檔案。
- **沒有新增實測精度結論。** 延續天文台氣象輸入核對及用戶提供電錶紀錄的核對入口；尚無真實村屋發電紀錄，亦沒有完整颱風、結構或電氣串列模型。

The 35° reference is not forced to pass incompatible clearance/coverage assumptions. Financial objectives may select the same option at the default quote. These examples are not legal certifications. The external Windows script was unavailable locally; equivalent repository regressions were used. No field accuracy or wind/structural certification is claimed.

The official guide supports the covered-area limit. Roof/object/neighbour geometry, access gap, rotated row-density criterion and quotes are assumptions, identified in the bilingual UI, README and metadata/exports.
