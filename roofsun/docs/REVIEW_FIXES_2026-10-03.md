## 财务复核例子

默认 8×6 m 天台、20°、正南、三排、2027-01-01 投产：18 块，8.1 kW，年发电约 9,887 kWh。成本假设改为 25,000/kW + 5,000 后，持续回本约 5.4 年；无 2033 年后收入的 NPV 约 HK$22,097。安装总报价 NPV 保本上限约 HK$229,597，发电量固定下调 15% 后上限约 HK$193,936，低于当前 HK$207,500 估算。因此不能将默认结果宣传为稳健的“约三年回本”。

这些是模型结果，非商业报价和发电保证。气象输入下降 15% 的物理情景会改变温度损失；报价压力测试则直接将发电度数乘 0.85，两者假设有所区别。

## 复现命令

在 `roofsun/` 按 README 配置环境，然后执行 `python -m pytest -q`、`python scripts/validate.py`、`npm run build`。启动本地 API 后执行 `ROOFSUN_TEST_URL=http://127.0.0.1:8000 npm run test:browser`。测试中的电表记录属于明确标记的合成测试输入，不是项目的实测证据。
